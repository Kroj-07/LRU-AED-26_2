## Requisitos

- Compilador C++23
- Python 3 + Manim, para renderizar las escenas de animación

## Cómo compilar y ejecutar las pruebas

1. Abre la carpeta del proyecto en CLion.
2. Elegir el target **`test_lru`**.
3. Darle run para generar los trace.jsonl

> El proyecto también incluye el target `main_A`, que corresponde a las
> pruebas propias de la implementación de la LRU Cache — no es necesario
> para generar los traces de la animación.
